If you already have records under the old DATA/ workspace files, connecting migrates them in automatically. Requires Chrome or Edge.

Data Management
Get your records out at any time — works with or without a connected workspace folder.
Export Examination History: downloads every record currently loaded (name, employee #, department, section, hired date, exam type, score, pass/fail, full per-set breakdown) as one CSV — this is your complete, self-sufficient backup and the way to hand data off between machines. Export Dashboard Summary: a quick totals snapshot (pass rate, active/expiring/expired certificates, etc.) as its own small CSV. Backup System: downloads the history CSV plus a settings/configuration file together, for safekeeping. All three always export everything currently loaded, regardless of any filter set on the Dashboard.

Exam Mode
What gets administered — and what the certificate reflects.
Both: the exam runs the Actual Examination (all enabled sets) followed by the Photo Examination, and the certificate lists results from both. Actual Only / Photo Only: the exam skips the other type entirely — regardless of which individual sets or folders are enabled below — and the certificate's wording and score breakdown reflect only the type actually given. This is a single top-level switch, faster than disabling every set/folder one by one.
2
Photo Exam Sets
Choose which photo folders are given, and how many images to draw from each.
Folders are read straight from the uploaded Photo Answer Key (Admin, Step 2) — new folders appear here automatically as the image bank grows, nothing to configure by hand. Uncheck a folder to leave it out of exams entirely. The number field controls how many images are randomly sampled from that folder per attempt (never more than what's actually available).
3
Actual Exam Sets
Choose which sets are given, per category.
Sets are read from the uploaded Actual Exam Answer Key (Admin, Step 2), grouped into columns by category (Trailing, Pole, ABS, and any new category that appears later). Uncheck a set to leave it out of exams. Unlike Photo folders, every question in an enabled set is always given — sets aren't randomly sampled.
4
Examination Time
Actual and Photo run on their own independent countdowns.
The Actual Exam timer covers all enabled Trailing/Pole/ABS sets together as one continuous block. The moment the exam crosses into the Photo Exam, that timer stops and the Photo timer starts fresh — they never share time. If a timer runs out mid-exam, the app automatically moves forward (into Photo, or straight to submission) rather than freezing.
5
Passing Rates & Certificates
Controls scoring, and how long an issued certificate stays valid.
Passing Rate is the minimum overall score (%) required to pass — set separately per Position (Production Inspector, QA). Exam Type (Certification/Correlation) is a separate classification chosen at exam setup and controls which Certificate Validity period applies. Retake Wait Period is the minimum number of days before someone who failed is allowed to attempt the exam again (informational — the app doesn't currently block early retakes, it's a reference figure for admins).
